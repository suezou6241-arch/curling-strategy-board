# カーリング作戦ボード (Curling Strategy Board)

スマートフォンの縦画面で、カーリングの作戦を直感的に組み立てられるデジタル作戦ボードです。
[仕様書](../curling_strategy_board_spec.md) の MVP 機能範囲をもとに、React + TypeScript + Vite + SVG で実装しています。

## 実装済み機能 (MVP)

- カーリングシートの SVG 表示(ハウス / 各ライン / ハック / FGZ)
- スマホ縦画面向けレイアウト(ボタンは 44px 以上)
- 投球方向の上下反転(表示視点のみ切替、局面は不変、方向はデータに保存)
- ストーンの追加(タップ)/ 移動(ドラッグ)/ 削除
- 自チーム(赤)/ 相手(黄)の切り替え
- 投球軌道の描画(ドラッグ)と削除、ショット種類の選択
- Undo / Redo(方向反転は対象外)
- エンド設定、先攻 / 後攻(ハンマー)切替
- 作戦タイトル・コメントの入力
- 局面のローカル保存(localStorage) / 一覧からの呼び出し / 削除 / 新規作成

## 動かし方

Node.js が必要です(検証環境: Node 24 / npm 11)。

```bash
cd curling-app
npm install        # 初回のみ
npm run dev        # 開発サーバー起動 → http://localhost:5173/
```

本番ビルド:

```bash
npm run build      # dist/ に出力
npm run preview    # ビルド結果をローカルで確認
```

スマホ実機で確認する場合は、`npm run dev` 起動時に表示される `Network:` の URL を
同一 Wi-Fi 上のスマホのブラウザで開いてください。

## 使い方

1. ヘッダーでチーム名・エンド・先後攻を設定
2. 「石を置く」タブ → 置きたいチーム(赤/黄)を選び、シート上をタップ
3. 「選択/移動」タブ → ストーンをドラッグで移動、選択して「石削除」で削除
4. 「軌道を描く」タブ → ショット種類を選び、シート上をドラッグして軌道を描画
5. 「投球方向」ボタンでシート全体を 180° 反転(自分の視点に合わせる)
6. 「作戦」ボタンで作戦タイトル・メモを記入
7. 「保存」で局面を保存、「呼出」で保存済みの局面を読み込み

## 座標系について

ストーン・軌道の座標は 0〜100 の相対値で保持しています(x: 左→右、y: 遠端→投球側)。
投球方向 `up` のときは表示時に 180° 回転して描画しますが、保存データは常に `down` 基準の
論理座標で持つため、方向を変えても局面の相対位置関係は保たれます。

## 構成

```
curling-app/
├─ index.html
├─ src/
│  ├─ main.tsx        エントリ
│  ├─ App.tsx         画面全体・状態統合・保存/呼び出し
│  ├─ BoardView.tsx   SVG 上のストーン操作・軌道描画
│  ├─ Sheet.tsx       カーリングシート背景の SVG
│  ├─ geometry.ts     シートのジオメトリ定数・座標変換
│  ├─ types.ts        データモデル(Board / Stone / Shot)
│  ├─ storage.ts      localStorage 保存/読み込み
│  ├─ useHistory.ts   Undo / Redo 履歴フック
│  └─ index.css       スタイル
└─ ...
```
